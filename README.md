# AI-mini-project

## Project Description
This project focuses on Rainfall Prediction using Machine Learning.

## Dataset
The project uses historical rainfall data from India (1901–2015).

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Files
- rainfall in india 1901-2015.csv
- rainfall_prediction10.ipynb

## How to Run
1. Download the repository.
2. Open the Jupyter Notebook.
3. Run all cells to see the rainfall prediction results.
